# 私学・若手教員向け助成金ガイド

私立学校（幼稚園〜大学）の若手教職員が対象となる、日本国内の主な助成金・補助金制度をまとめたものです。学校法人の事務担当者や若手教員本人が、どの制度が使えそうかを大まかに把握するための資料です。実際の申請にあたっては、必ず各実施団体の最新の公募要領・要綱を確認してください。

## 1. 全体像

「私学」「若手」に関わる助成金は、大きく次の4系統に分かれます。

| 系統 | 実施主体 | 対象 | 主な内容 |
| --- | --- | --- | --- |
| ① 研修参加費・研修運営費の助成 | 都道府県の私学教育研究所・私学財団 | 私立小中高の若手教員（会員校） | 全国研修会の参加費助成、校内研修講師謝金助成 |
| ② 経常費補助金（一般補助・特別補助） | 国・都道府県 | 学校法人（間接的に教職員の待遇改善に活用） | 教職員の資質向上・研修実施への加算 |
| ③ 私立大学等経常費補助金の特別補助 | 日本私立学校振興・共済事業団（私学事業団） | 私立大学等（若手研究者支援に取り組む大学） | 若手研究者のポスト確保・年俸制導入等への補助 |
| ④ 科学研究費助成事業（科研費）「若手研究」 | 日本学術振興会（JSPS） | 私立大学教員を含む若手研究者個人 | 研究課題への直接助成（個人申請） |

以下、それぞれ詳しく解説します。

## 2. 若手教員の研修参加費・研修運営費の助成

私学教員に最も身近なのがこの系統です。学校法人単位で申請・活用します。

### 2-1. 日本私学教育研究所「私立学校若手教員（初任者等）全国研修会」

- 実施主体：一般財団法人 日本私学教育研究所（[shigaku.or.jp](https://www.shigaku.or.jp/)）
- 対象：おおむね経験年数5〜10年程度の私立中学・高等学校教員
- 内容：私学教員にとってタイムリーかつ実践的・具体的な課題を扱う全国規模の研修会
- 関連して「私立学校初任者研修地区研修会」「私立学校中堅教員研修会」も実施

### 2-2. 都道府県の私学教育研究所・私学財団による参加費助成

例：東京私学教育研究所（一般財団法人東京私立中学高等学校協会）

- 令和3年度から、日本私学教育研究所主催の研修会に会員校の教職員が参加する際の**参加費を助成**する事業を実施。
- 会員校が校内研修を実施する際に外部講師を招く場合、**講師謝金を助成**（外部講師の場合など、金額例：3万5,000円）する制度もあり。
- 申請はオンライン申請ページから行う（[k.tokyoshigaku.com](https://k.tokyoshigaku.com/supervisor/apply.html)）。

他の都道府県でも、私学財団・私学協会・私学教育研究所が同種の研修費助成を行っていることが多いため、学校所在地の団体（都道府県私立中学高等学校協会等）に確認するのが近道です。

## 3. 私立学校経常費補助金（一般補助・特別補助）

- 実施主体：都道府県（国からの間接補助を含む）
- 対象：学校法人（幼稚園〜高等学校）
- 制度概要：学校法人の経常的経費（教職員人件費・教育研究経費等）を補助する「一般補助」と、特色ある取組みを支援する「特別補助」からなる。
- 若手教員との関わり：特別補助の配分基準の中に、教職員研修の実施状況や若手教員の育成・処遇改善に関する加算項目が設けられている場合がある（都道府県ごとに基準が異なる）。
- 参考：
  - 文部科学省「私立高等学校等経常費助成費補助金交付要綱等」（[mext.go.jp](https://www.mext.go.jp/a_menu/koutou/shinkou/07021403/002/002/012_00001.htm)）
  - 東京都生活文化局「私立学校経常費補助金」（[seikatubunka.metro.tokyo.lg.jp](https://www.seikatubunka.metro.tokyo.lg.jp/shigaku/kankeisya/hojokin/josei/youshiki/0000000794)）

学校法人の経理・総務担当者が、都道府県私学担当課の年度ごとの交付要綱を確認して申請する制度であり、教員個人が直接申請するものではありません。

## 4. 私立大学等経常費補助金の特別補助（若手研究者支援）

- 実施主体：日本私立学校振興・共済事業団（私学事業団、[shigaku.go.jp](https://www.shigaku.go.jp/s_hojo_menu.htm)）
- 対象：私立大学・短期大学等（法人単位で申請）
- 制度概要：一般補助（教育研究に係る経常的経費）と特別補助（各大学の特色ある取組み）に分かれ、特別補助の中に「大学院における若手研究者支援」の項目がある。国立大学同様の年俸制導入や業績管理体制の整備など、若手研究者の育成・登用に積極的に取り組む大学に加算される仕組み。
- 参考：私立大学等経常費補助金交付要綱（文部科学省）／私立大学等経常費補助金 配分基準別記7（特別補助）（私学事業団）

こちらも大学（学校法人）単位の制度で、教員個人が直接受け取るものではなく、大学の制度（年俸制ポスト等）を通じて若手研究者に還元される形です。

## 5. 科学研究費助成事業（科研費）「若手研究」

若手の**研究者個人**が直接申請できる、最も代表的な公的研究助成です。私立大学の教員も対象に含まれます。

- 実施主体：日本学術振興会（JSPS）／文部科学省
- 対象：博士の学位取得後8年未満の研究者など、一定の要件を満たす若手研究者（詳細な年齢・資格要件は毎年度の公募要領で確認が必要）
- 助成規模の目安：採択率はおおむね40%前後、1件あたり最大500万円程度（研究期間・分野により変動）
- 令和9（2027）年度分の公募：令和8（2026）年7月14日公募開始、締切は例年9月中旬頃（直近の令和8年度分は2025年9月17日締切）
- 参考：
  - JSPS「若手研究 公募情報」（[jsps.go.jp](https://www.jsps.go.jp/j-grantsinaid/02_koubo/kiban.html)）
  - JSPS 公募要領PDF（基盤研究・挑戦的研究・若手研究）

私立学校（大学）に所属する若手教員自身が研究者として申請する制度であり、上記2〜4の「学校法人向け」制度とは性質が異なる点に注意してください。

## 6. どの制度を見るべきか（早見表）

| あなたの立場 | まず確認すべき制度 |
| --- | --- |
| 私立中学・高校の若手教員本人 | ②-2 都道府県私学教育研究所・私学財団の研修参加費助成（勤務校経由で申請） |
| 私立中学・高校の学校法人（総務・経理） | ③ 私立学校経常費補助金（一般補助・特別補助） |
| 私立大学の学校法人（企画・研究支援課） | ④ 私立大学等経常費補助金の特別補助（若手研究者支援） |
| 私立大学に所属する若手研究者本人 | ⑤ 科研費「若手研究」（個人申請） |

## 7. 注意事項

- 各制度の対象年齢・経験年数・助成額・締切は年度ごとに改定されるため、本資料はあくまで概要の把握用です。
- 学校法人向けの補助金（経常費補助金等）は、都道府県ごとに交付要綱・配分基準が異なります。学校所在地の都道府県私学担当課、または加盟する私学財団・私学協会に直接確認してください。
- 科研費など研究者個人向けの制度は、応募資格（学位取得後の年数など）が毎年度見直されることがあるため、最新の公募要領を必ず参照してください。
